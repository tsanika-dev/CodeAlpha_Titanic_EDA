# 🚢 CodeAlpha Task 2: Exploratory Data Analysis (EDA)

## 📌 Project Title
**Titanic Dataset - Exploratory Data Analysis**

## 📖 Project Overview

This project was completed as part of the **CodeAlpha Data Analytics Internship**.

The objective of this project is to perform **Exploratory Data Analysis (EDA)** on the Titanic dataset using Python. The analysis focuses on understanding the dataset, cleaning missing values, exploring relationships between variables, and discovering meaningful insights through statistical analysis and data visualization.

---

## 🎯 Objectives

- Understand the Titanic dataset.
- Perform data cleaning and preprocessing.
- Identify missing values and duplicate records.
- Analyze passenger demographics and survival patterns.
- Create meaningful visualizations.
- Generate insights from the data.

## 💡 Key Insights

- Female passengers had a significantly higher survival rate than male passengers.
- First-class passengers were more likely to survive compared to lower classes.
- Age and fare showed varying distributions among passengers.
- Missing values were identified and handled appropriately.
- Exploratory analysis revealed important survival trends and passenger characteristics.
